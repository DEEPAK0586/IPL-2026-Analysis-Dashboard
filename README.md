📊 Project Overview

The IPL 2026 Analysis Dashboard is an interactive Excel-based data analysis project built using IPL 2026 ball-by-ball data.

The objective of this project is to transform raw cricket data into meaningful insights about players, teams, bowling performances, matches, and venues using Microsoft Excel.

The dashboard provides an easy-to-understand visual summary of the IPL 2026 season.


🎯 Project Objectives

• Analyze IPL 2026 match and ball-by-ball data
• Identify top-performing batsmen
• Analyze bowling performances
• Compare team performance
• Analyze venue-wise statistics
• Create meaningful KPIs
• Convert raw data into interactive visualizations
• Present complex data in a simple dashboard

📑 Workbook Structure

1. Raw_Data

Contains the original ball-by-ball IPL 2026 dataset.

2. Pivot_Analysis

Contains pivot-based calculations and supporting analysis used for the dashboard.

3. Batting_Analysis

Contains player batting statistics such as:

• Total Runs
• Fours
• Sixes
• Top Run Scorers

4. Bowling_Analysis

Contains bowling statistics such as:

• Total Wickets
• Economy Rate
• Top Bowlers

5. Venue_Analysis

Contains venue-level analysis including:

• Runs by Venue
• Average Score
• Match Performance by Venue

6. Dashboard

The final interactive dashboard containing the major IPL 2026 insights.
